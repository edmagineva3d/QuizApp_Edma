# Frontend Quiz

A React + TypeScript quiz application built with Vite based on the provided Quiz App activity guide.

## Features
- Home page with Start Quiz button
- 10 multiple-choice questions stored as an array of objects
- Question navigation and state management
- Score and percentage calculation
- Result page with retake and return home actions
- React Router routing
- Reusable components
- Responsive CSS with hover, selected-answer, gradient-button, and smooth motion effects

## Run

```bash
npm install
npm run dev
```
